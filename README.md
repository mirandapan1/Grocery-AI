# Grocery-AI

Grocery AI, or Fridge2Food, is an AI run website that allows users to quickly analyze the food avaiable in one's fridge by providing relevant recipes based on user preferences and item avaiabllity.

## Running the Program

In the terminal install the program locally using npm:
$ cd grocery-app/
$ npm install (?)
$ npm run dev

### Incorporating A Research Paper

The article, DietHub: Dietary habits analysis through understanding the content of recipes, by Matej Petković et. al is an AI workflow that describes the relationship between food and AI by highlighting the idea behind recipes. By learning the ways to 'tag' recipes and catorizing them, AI is able to come to a better understanding and thereby make smarter recipe recommendations. Similarly seen in our Fridge2Food project, there is the option of adding preferences to the recipes by adding specfic tags relating to 'Cuisine, Diet, and Cooking Style'. Although currently, this project only has simple categories as these; in the future, additions such as an integrated calorie system or vitamin/nutritional content may allow for even better recipes.

Petković, M., Popovski, G., Seljak, B. K., Kocev, D., & Eftimov, T. (2021, January). DietHub: Dietary habits analysis through understanding the content of recipes, Trends in Food Science & Technology. Science Direct. https://www.sciencedirect.com/science/article/pii/S0924224420306403

##### Working with an AI Agent

Ada: I used the AI agent to help me with understand API models and how to implement them in the backend work but also connecting it with frontend calls. In the beginning of this project I prompted an AI Agent to explain to me how API key worked and how to add that and API models into a class. I made many mistakes throughout this project, whether it be adding the wrong models or linking the wrong API url. However, the Agent really helped me save time when I would prompt it to generate console logs to place throughout the code to debug issues. After this project, I've learned that when prompting, I should double check the code blocks the Agent may be outputting because it isn't always accurate or helpful to the specific sections I work on. Next time, I would keep in mind to not prompt for huge tasks at the very beginning as it would lead to confusion on how specific functions or methods work.
